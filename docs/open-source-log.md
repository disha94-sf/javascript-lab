**Type** is one of: `bug fix`, `feature`, `docs`, `tests`, `typo`.
**Status** is one of: `open`, `merged`, `closed`.

## How I pick issues

1. Search GitHub for `label:"good first issue" language:JavaScript is:open no:assignee`.
2. Choose projects I actually use, with recent activity and a friendly CONTRIBUTING guide.
3. Comment on the issue to ask if I can take it before starting.
4. Keep each pull request small and focused, with tests.
